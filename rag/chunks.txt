2. Role Overview:- 
➔​ Role Overview 
This Portal has multiple users of different roles for each station. Each role has 
specific jobs to perform. These roles are: 
1. Station Admin. 
2. Secretary Executive. 
3. Program Executive 
4. Signing Authority/H.O.P. 
5. Account officer. 
6. Artist. 
Each Station must have Station Admin credentials to start Artist/Talent Booking 
Software (ABS/TBS). For Station Admin Credentials, the following details are to 
be sent to the email address “support@prasarbharati.gov.in” with ‘ABS’ in the 
subject line: 
1. Station Name 
2. Station Address 
3. Head of Program Name 
4. Head of Program Email ID 
5. Head of Program Mobile No.

Manage Booking: 
a) Click on Book Artist. 
b) Select the Main Category (Number of bookings for Resource Person-1 per

c) Select the Expertise.

5. Frequently Asked Questions (FAQs) for Station Admin/ 
Secretary Executive/ Program Executive/ Signing Authority/ 
Account Officer:- 
Que 1. How can I log in to the ABS Portal? 
Ans: 
●​ Use your Login Credentials to log in at https://abs.prasarbharati.org/​

●​ Authentication uses OTP sent to your registered mobile and email (2FA enabled) 
Que 2. How to update or allow the backdate? 
Ans: Follow the steps below to proceed successfully: 
1. Log in with the Station Admin Role. 
2. Click on the "Allow Back Date" module. 
3. In the Allow till field, select tomorrow's date and time 
4. Enter the description/remarks and submit. Log out of the Admin role. 
5. Now, log in with the Pex/SecEx role, go to the Book Artist Module, and select the 
back date (Back date will be visible here after you have followed the above steps 
properly).

Certificate' option for assignees and artists. How to assign duty?

email id login.
